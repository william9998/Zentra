# Zentra 開工對齊

先定位含 AGENTS.md 與 specs/SPEC.md 的專案根目錄；以下路徑皆相對根目錄。
若指定任務，先讀 coordination/handoffs/<id>/ 中給你的交接單。
讀 AGENTS.md、specs/SPEC.md、ADR-0005、ADR-0006、specs/glossary.md 與 coordination/BOARD.md。
指定任務時再讀 specs/features/<id>/ 的規格、驗收條件、涉及的契約與自身角色 Markdown。
未指定任務只整理現況，不自行挑選任務開工；不存在的檔案如實標明。

簡潔回報產品一句話、實際 SPEC 版本、P1–P5、進行中與阻塞任務。
針對指定任務回答 AGENTS.md 的五項對齊問題，引用依據。
區分 BOARD 的範例提問與真實未決問題；不把文件中的完成宣稱當成測試證據。
指出發現的規格矛盾、缺檔或過時指引，以及應由哪個角色處理。
本技能唯讀，不變更 BOARD、不實作功能，也不宣稱品質閘門已通過。
